# Learning Systems & Functional Languages — notes + practical

A small tutorial for Python/Go developers learning **Rust, Zig, and Swift**, with side-by-side comparisons,
mental models, gotchas, and practice exercises.

- `notes.md` — the main tutorial (start here).
- `examples/` — small runnable snippets.

Rust and Swift compilers are available locally (`rustc`, `swiftc`); Zig is not installed, so Zig snippets are
provided as static examples.

## Quick run

```bash
# Rust
cd examples && rustc hello.rs -o hello && ./hello

# Swift
swiftc hello.swift -o hello_swift && ./hello_swift
```
